# Minimal Synthetic Example

This directory shows the smallest useful shape of the starter without containing any real project data.

The example product is a fictional task-tracking web app.

## Included

- `CLIENT_REQUIREMENTS_CURRENT.md` — synthetic client intent.
- `PRODUCT_STATE_CURRENT.json` — current product state.
- `CAMPAIGN_001_CHARTER.json` — first strategic campaign.

## Intended flow

1. Fresh Planner reads the starter protocols.
2. Planner reconstructs requirements and Product State.
3. Planner sees that task creation/completion is not implemented.
4. Planner emits one bounded campaign charter.
5. I3 Campaign Lead owns tactical implementation and verification.
6. A fresh-context probe should be able to reconstruct the same posture without chat history.

The example deliberately stops before implementation. It demonstrates authority/state/charter shape, not a fake product PASS.
