## 2026-10-19 technical expansion (candidate 0.1.0-candidate.2)

Portable L2 handoff: `tools/engineering_packet.py` builds and checksum-verifies a bounded source-complete SIP ZIP; `l2-two-zip-preflight` consumes historical daypack+L3 Goal Progress ZIP, while `two-zip-preflight` consumes SIP+Goal ZIP for L3. This is tool-level integrity, NOT independently verified currentness/host resume.

Local authentication: `tools/gemini_keyfile.py` selects exactly one explicit `gemini<number>.txt` key from a configured local directory without printing it. A key never proves that the project/model/quota are free; `tools/cognitive_i4.py` keeps the separate USD 0 proof and export gates. Do not copy the key or private source into ZIPs.

Model names do not identify I3/L3 or I4/L4, Goal, engine or version. L3 model/effort is CLIENT-selected per Goal; L3 independently selects a suitable economical high-effort L4 option after actual host readback. The portable starter does not simulate Codex native resume or global OWNER broker.
