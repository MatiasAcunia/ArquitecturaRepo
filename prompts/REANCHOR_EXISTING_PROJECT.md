# Prompt — Re-anchor an Existing Project

Use when the project already has months of history, multiple agents or contradictory state.

---

Reconstruct this project's current Agentic SDLC from physical evidence.

Start as UNTRUSTED_CONTEXT.

Do not trust chat continuity, newest-looking files, historical handoffs or worker PASS reports by default.

Determine:

1. final client-visible product;
2. current explicit CLIENT requirements and unresolved product questions;
3. product/workstream topology;
4. exact role authorities;
5. canonical current-state owners;
6. stale/superseded/prepared-but-inactive surfaces;
7. current code/DB/runtime truth;
8. active campaign and checkpoint/terminal authority;
9. current verification gate;
10. strongest exact evidence;
11. current critical path;
12. next legal and forbidden actions.

Then compare the project against the starter protocols.

Repair the smallest causal set of continuity/authority defects necessary for a fresh context to reconstruct one coherent posture.

Do not create another giant handoff or duplicate policy to mask conflicting owners.

Return:

- reconstruction;
- contradictions;
- exact canonical owner for each concern;
- changes applied;
- fresh-context falsifier;
- remaining HOLDs;
- next legal campaign boundary.
