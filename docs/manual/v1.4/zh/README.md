## 选择正确的资料

1. 只需了解概念和首次操作：从[迷你指南](../../../i18n/MINI_GUIDE_zh.md)及[FAQ](../../../i18n/FAQ_zh.md)开始。
2. 希望理解完整方法：阅读此处八章，或下载对应的完整排版 PDF。
3. 确认当前执行命令：[v1.4 公开安装指南](../../../46_V1_4_PUBLIC_START_AND_SUPPORT.md)和[发行与升级说明](../../../47_V1_4_RELEASE_NOTES_AND_UPGRADE.md)。
4. 使用固定发行包：从[GitHub v1.4.0 Release](https://github.com/MatiasAcunia/ArquitecturaRepo/releases/tag/v1.4.0)获取带校验值与清单的 ZIP。

这些完整的多语言手册是在 v1.4.0 标签发布后添加到 main 的文档，**不在当时的发行 ZIP 中**。新版本文档不能追溯地改变旧包的内容。安装到真实应用时，应核实使用的准确发行标识。

本书不会自动安装 LLM、批准费用、公开代码或完成某个产品。俱乐部只是解释需求与工程流程的虚构例子。真实应用的现行代码、数据库、用户决策与实际验证优先于示例和聊天总结。

PDF 的页数取决于排版。对于历史版不存在或无法确认的插图，不会编造“已恢复”的素材。任何技术主张应当能够追溯到正确的公开来源。
