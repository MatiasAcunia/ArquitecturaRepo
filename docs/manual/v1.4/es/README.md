## Lectura recomendada

1. Para probar en cinco minutos, usá la [miniguía](../../../i18n/MINI_GUIDE_es.md) y el [inicio público v1.4](../../../46_V1_4_PUBLIC_START_AND_SUPPORT.md).
2. Para entender el método y operar con criterio, leé estos ocho capítulos extensos.
3. Para descargar la distribución v1.4.0 exacta, usá el [GitHub Release publicado](https://github.com/MatiasAcunia/ArquitecturaRepo/releases/tag/v1.4.0). El ZIP versionado es un snapshot anterior y **no contiene automáticamente los documentos incorporados a `main` después de la publicación**.
4. Dentro de un producto real, tienen prioridad los requisitos confirmados, código, DB, Product State y evidencia actuales de ese proyecto, no los ejemplos genéricos del manual.

El manual es neutral respecto del modelo de IA. No instala un LLM ni habilita proveedores de pago, despliegues o publicaciones externas. El ejemplo del club es para aprender y no afirma que exista una aplicación terminada.

## Diferencia entre ediciones

- **Español v1.4:** el manual extenso actual, con ocho capítulos completos y fuentes actualizadas.
- **Inglés y portugués v1.4:** ediciones completas independientes con fuentes y PDF propios.
- **Español v1.3:** la edición histórica original, que se mantiene sin sobrescribir ni atribuirle características futuras.
- **Miniguías v1.4:** ocho textos breves en idiomas diferentes, útiles para comenzar, pero no sustituyen manuales de unas 60 páginas.

La paginación depende de tamaño y tipografía, por lo que el PDF generado no necesariamente conserva los saltos físicos del documento histórico. Las figuras del Markdown histórico son descripciones; no se inventaron ilustraciones que no estuvieran disponibles.
