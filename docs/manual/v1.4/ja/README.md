## どれを読めばよいか

1. すぐに概要を知りたい場合：[日本語ミニガイド](../../../i18n/MINI_GUIDE_ja.md)と[FAQ](../../../i18n/FAQ_ja.md)。
2. 全体を理解したい場合：本書の全八章と、同じ内容を収録した日本語の組版PDF。
3. 導入コマンドを確かめたい場合：[v1.4の公開導入ガイド](../../../46_V1_4_PUBLIC_START_AND_SUPPORT.md)と[リリースノート](../../../47_V1_4_RELEASE_NOTES_AND_UPGRADE.md)。
4. 配布物を固定して導入したい場合：[v1.4.0リリース](https://github.com/MatiasAcunia/ArquitecturaRepo/releases/tag/v1.4.0)のZIPとSHA-256マニフェスト。

本書のように公開後mainへ追加された長編マニュアルは、過去に作成されたv1.4.0のZIPには入っていません。アプリケーションへ導入する場合は、元のリリース内容と現在の追加文書を混同しないでください。

架空のクラブの操作例は実際の製品の受け入れ証拠ではありません。スターターはAIモデルを追加導入せず、外部公開や課金を認可せず、製品を自動的に完成させません。導入先の実際のコード、DB、利用者の決定が優先されます。

ページ数は組版によって変化します。歴史的な版の回収できない図版を再現したと偽ることはありません。リンクの不備や技術的な誤りは、実際のソースに照らして修正します。
