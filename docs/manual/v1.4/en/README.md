## Which manual should I use?

1. For your first five minutes, use the [mini guide](../../../i18n/MINI_GUIDE_en.md) and the [public v1.4 start guide](../../../46_V1_4_PUBLIC_START_AND_SUPPORT.md).
2. For context, decisions, examples and operational detail, use these eight complete chapters.
3. For the exact v1.4.0 archive, download and verify the [published GitHub Release](https://github.com/MatiasAcunia/ArquitecturaRepo/releases/tag/v1.4.0). The published v1.4.0 ZIP is an earlier source snapshot and should not be assumed to contain documentation merged to `main` afterward.
4. For actual project work, the adopted repository's current requirements, source, Product State, authority and evidence take precedence over generic examples here.

This manual is model-neutral. It neither installs an LLM nor authorizes paid providers, production deployment or external publication. The club example is instructional, not a prebuilt app.

## Language and publication status

Eight source-verified full-length v1.4 books are now available. The [canonical edition index](../../../../README.md) links each of the eight language editions and its PDF, without duplicating an increasingly stale translation list here. Each of the eight short localized guides remains a separate introductory summary, not a substitute for a complete handbook.

The original illustrated PDF had approximately 60 pages. Pagination depends on page size and typesetting; the Markdown chapter numbers preserve content order, not the original fixed page breaks. The figures in the historical Spanish Markdown were caption-only transcriptions. This v1.4 edition explains those relationships in text and tables without claiming to reproduce missing original graphics.
