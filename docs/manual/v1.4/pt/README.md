## Como começar

1. Para experimentar rapidamente, consulte o [miniguia](../../../i18n/MINI_GUIDE_pt.md) e o [primeiro uso público v1.4](../../../46_V1_4_PUBLIC_START_AND_SUPPORT.md).
2. Para tomar decisões, entender recuperação e coordenar um produto, leia estes oito capítulos extensos.
3. Para instalar a distribuição exata v1.4.0, obtenha o [GitHub Release](https://github.com/MatiasAcunia/ArquitecturaRepo/releases/tag/v1.4.0) e confira checksum e manifest. A branch `main` inclui documentação posterior que **não está automaticamente no ZIP já publicado**.
4. Num produto real, requisitos, código, dados, Product State e evidência canónica desse produto prevalecem sobre os exemplos genéricos do livro.

O framework é neutro quanto ao modelo de IA. Este manual não instala nem autoriza um LLM, serviço pago, publicação, deploy ou acesso a dados privados. O exemplo do clube é didático, não uma aplicação pronta.

## Edições e versões

- **Português v1.4:** esta edição completa, separada do miniguia.
- **Espanhol, inglês e francês v1.4:** edições extensas independentes, com PDFs e fontes próprias.

- **Miniguias v1.4:** resumos breves nos oito idiomas suportados pela navegação do starter.

O PDF é composto a partir dos capítulos Markdown. A quantidade de páginas depende de tipografia e formato; a ordem dos oito capítulos preserva a estrutura de aprendizagem. As descrições de figuras históricas não representam imagens originais recuperadas quando essas imagens não existem na fonte.
